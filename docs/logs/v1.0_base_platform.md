# Log: v1.0 — Base Platform (Pre-Expansion)

**Date:** Pre-March 2026
**Branch:** `main`
**Status:** ✅ Deployed to Vercel

---

## Summary

Initial release of the OneServe civic services platform with the core feature set.

## Features Implemented

### Authentication
- Email/password signup and login via Supabase Auth
- OTP email verification (custom Resend-based system)
- Role selection at login (Citizen / Admin)
- Auto-profile creation on login if missing
- Forgot password flow

### Citizen Features
- **Dashboard** — Quick stats (active complaints, pending bills, reward points) + service grid
- **Complaint Registration** — Text and/or photo input, category selection, GPS auto-detect, manual address with searchable state/city dropdowns, image upload to Supabase Storage
- **Complaint Tracking** — Two-column layout (Processing / Processed), real-time status updates via Supabase Realtime, complaint deletion with worker detachment
- **Bill Payment** — UI simulation for electricity, water, gas bills
- **Bill Management** — Bill overview and management
- **Gamification Hub** — Points, badges, leaderboard (hardcoded demo data)
- **Notifications** — Notification center
- **AI Assistant** — Simulated chatbot with keyword-based responses
- **Feedback** — Star rating + text submission form
- **Settings** — Profile management (name, phone, address)
- **Government Schemes** — Information page
- **Account Deletion** — Full cascade delete via RPC

### Admin Features
- **Admin Dashboard** — Stats overview, complaint table with search/filters, detail modal with status management
- **Staff Assignment** — ManpowerModal with role-based filtering, availability check, staff detail panel, assignment confirmation with email notification
- **Admin Settings** — Admin-specific settings page

### Backend / Infrastructure
- Supabase PostgreSQL with 3-layer architecture (raw_complaints → processed_complaints → staff)
- PostGIS enabled for geospatial queries
- Row Level Security (RLS) on all tables
- SECURITY DEFINER RPCs for complex cross-table operations
- Vercel serverless function (`/api/send-email.js`) for email dispatch
- Local Express dev server for development
- Nodemailer integration for OTP, complaint confirmation, staff assignment emails

### Database Tables
- `profiles` — User identity and role
- `citizens` — Citizen-specific data
- `raw_complaints` — Original citizen submissions (Layer 1)
- `processed_complaints` — Admin metadata and status (Layer 2)
- `staff` — Workforce management (Layer 3)
- `otp_codes` — Custom OTP storage

## Known Limitations (at this version)
- No worker/field agent interface
- No citizen rating system for completed work
- No document verification for special roles
- No priority escalation over time
- Static ETA values (not computed from real data)
- No admin hard-delete for complaints
- Some placeholder/non-functional UI elements
- Gamification data is hardcoded
- Bill payment is UI-only simulation
