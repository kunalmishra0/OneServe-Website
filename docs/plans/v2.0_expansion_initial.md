**Status:** Superseded by v2.0-revised

## Context

First draft of the 12-feature expansion plan for OneServe. Created after thorough codebase research.

## Key Decisions in this Draft
- 6-phase incremental approach (non-breaking)
- New `worker` role as third user type
- Worker onboarding via invite code system
- Priority escalation system
- Dynamic ETA computation

## Open Questions (at time of creation)
1. Supabase Pro availability (pg_cron) — **Answer: No**
2. Worker onboarding preference — **Answer: Option A (Invite Code)**
3. PostGIS availability — **Answer: Enabled**

## Changes from this Plan → Revised Version
- Added 4th database layer (`completed_complaints`) per user feedback
- Redesigned ETA to be calendar-aware with historical averages
- Adopted client-side escalation fallback (no pg_cron)
- Ratings stored in `completed_complaints` instead of separate table
